📋 地籍資料查詢系統

不動產地籍查詢整合工具｜Windows 電腦程式

💻 這是 Windows 電腦程式，請在 Windows 電腦上開啟這個網頁，下載安裝使用。

這是什麼？

專為不動產從業人員設計的整合工具：把原本要在很多個政府網站查詢、下載、整理的工作，整合成半自動流程，自動建立案件資料夾並存成 PDF。

  • 輸入地址或地號，自動查出地段地號、建號（哪一戶）、社區名稱，建立案件資料夾
  • 電子謄本下載與結構化、土地增值稅估算
  • 一鍵查詢：使用分區、使用執照、V523、國土分區、地質雲、實價登錄等，自動截圖存檔
  • 物件調查表、實價登錄申報書（租）、業績分配表自動帶入產生

下載與安裝（Windows 電腦）

⬇ 下載安裝程式（最新版）

下載的是 ZIP 壓縮檔 tw-land-tools-setup_v版號.zip，約 250MB。

安裝四步驟

  1. 按上面的橘色按鈕下載 ZIP 壓縮檔。
  2. 在下載的 ZIP 檔上按右鍵 →「解壓縮全部」→「解壓縮」（不要直接在 ZIP 裡面點兩下）。
  3. 打開解壓縮出來的資料夾，雙擊「地籍資料查詢系統_安裝_v版號.exe」，依畫面一路按「下一步」（預設裝在 D:\地籍資料查詢系統，不需要系統管理員權限）。
  4. 完成後桌面會有捷徑；第一次開啟會自動下載幾個輔助工具，按「是」即可。
⚠️ 第一次執行時 Windows 若跳出藍色的「Windows 已保護您的電腦」：請按「其他資訊」→「仍要執行」。
（這是因為安裝程式沒有付費數位簽章，不是病毒。）

已經在用的電腦不用重裝，在程式右上角按「🔄」更新即可。　·　 需要直接下載安裝檔(.exe)：點這裡
