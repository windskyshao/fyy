新電腦安裝程式（含所有執行環境，裝好就能用）

📱 您現在是用手機開啟。這是 Windows 電腦程式，請用電腦開啟這個連結再下載安裝（可先按下方「分享到 LINE」或「複製連結」傳給自己）。
⬇ 下載安裝程式（最新版）

下載的檔名是 tw-land-tools-setup_v版號.exe，約 250MB。

安裝三步驟

  1. 按上面的橘色按鈕下載安裝程式。
  2. 雙擊下載的檔案，依畫面一路按「下一步」（預設裝在 D:\地籍資料查詢系統，不需要系統管理員權限）。
  3. 完成後桌面會有捷徑；第一次開啟會自動下載幾個輔助工具，按「是」即可。
⚠️ 第一次執行時 Windows 若跳出藍色的「Windows 已保護您的電腦」：請按「其他資訊」→「仍要執行」。
（這是因為安裝程式沒有付費數位簽章，不是病毒。）

已經在用的電腦不用重裝，在程式右上角按「🔄」更新即可。
