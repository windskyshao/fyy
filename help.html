系統簡介

地籍資料查詢系統是專為不動產從業人員設計的整合工具，將原本需要在多個網站查詢、下載、整理的工作，整合為半自動化流程。

主要功能

  • 自動建立案件資料夾結構
  • 電子謄本下載與結構化處理
  • 土地增值稅自動估算
  • 整合多個查詢系統（V523、使用執照、實價登錄等）
  • 物件資料表自動生成
  • 連續模式批次執行

系統優勢

  • 省時：原本需要1-2小時的查詢工作，縮短至15-30分鐘
  • 自動化：減少手動操作，降低錯誤率
  • 整合性：一個系統完成所有查詢工作
  • 結構化：自動整理檔案，方便後續使用

安裝與更新說明

📦 重要：本系統分「完整安裝包」與「程式更新檔」兩種

GitHub 上提供的是「程式更新檔」，不含執行環境（python_embedded）與 chromedriver，單獨無法運作。完整執行需要：

  1. 程式本體（GitHub 下載，或由程式內右上角「🔄」自動更新）
  2. python_embedded 執行環境（內含 selenium、Pillow、PyMuPDF、easyocr 等所有必要模組，因檔案大未放 GitHub）
  3. chromedriver（需配合您電腦的 Chrome 版本）

首次安裝（含所有模組）

請下載並解壓縮「完整安裝包」，它已包含 python_embedded 與 chromedriver，解壓後即可使用，不需另外安裝任何模組：

  • 完整安裝包（v1.1.7a）：點此下載（Dropbox）

後續更新

安裝過一次後不需重裝 python_embedded。程式啟動時會自動檢查新版，右上角「🔄」變紅即代表有更新，點擊即可自動下載並更新程式本體。

系統主介面分為三個頁面，可以隨時切換：

1. 主頁（預設頁面）

主頁包含所有主要查詢功能，分為三欄排列：

左欄 - 地籍查詢功能

  • 使用執照查詢：查詢建物使用執照（僅限高雄市）
  • 重要設施查詢：查詢周邊重要設施
  • V523 系統：查詢 V523 資料（僅限高雄市）

中欄 - 圖資查詢功能

  • 國土測繪圖資：查詢國土測繪圖資
  • 高雄都市計畫：查詢都市計畫分區
  • 國土分區查詢：查詢國土功能分區
  • 地質雲查詢：查詢地質資訊

右欄 - 整合功能

  • 實價登錄：切換到實價登錄頁面
  • 謄本與土增稅：切換到謄本與土增稅頁面
  • 連續模式（淺藍色）：批次執行多個查詢
  • 匯入封存（淺綠色）：匯入先前封存的案件

2. 實價登錄頁面

專門處理實價登錄查詢：

  • 內政部：使用內政部實價登錄系統
  • 104實價網：使用104實價網查詢
  • 回至主頁：返回主頁面

3. 謄本與土增稅頁面

專門處理謄本下載、結構化與土地增值稅計算：

左欄 - 資料來源

  • 全國地政電子謄本：下載電子謄本（PDF格式）
  • 全功能地籍資料查詢：全功能地籍查詢
  • 電子謄本結構化：將PDF謄本轉換為結構化資料

中欄 - 資料處理與土增稅

  • 讀取結構化JSON：讀取謄本資料並轉換為物件調查表
  • 財政部土增稅：使用財政部系統計算土地增值稅
  • 高雄土增稅估算：使用高雄市系統自動估算

右欄 - 設定/編輯/返回

  • 載入案件 data.json：切換不同案件
  • 編輯物件資料：編輯物件調查表資料
  • 回至主頁：返回主頁面

買賣案件完整操作流程

步驟 1：建立案件資料夾

  1. 點擊主頁左上角的「地籍便民系統」按鈕（橙色）
  2. 在彈出視窗中輸入：
  3. 縣市：選擇縣市（例如：高雄市）
  4. 行政區：選擇行政區（例如：大寮區）
  5. 地段：輸入地段名稱（例如：義堂段）
  6. 地號：輸入地號（例如：358-21）
  7. 點擊「確定」

系統會自動建立： - 案件資料夾：「大寮區義堂段-358-21」 - 7個子資料夾： - 0.謄本 - 1.基本資料 - 2.照片 - 3.行情 - 4.其他相關 - 5.委託 - 6.成交 - data.json 檔案（記錄地段地號資訊）

步驟 2：下載電子謄本

  1. 點擊右欄的「謄本與土增稅」按鈕，切換到謄本頁面
  2. 點擊左上角的「全國地政電子謄本」按鈕
  3. 系統會開啟電子謄本下載網站
  4. 手動操作：
  5. 登入帳號
  6. 輸入地段地號
  7. 選擇謄本類型（土地謄本、建物謄本）
  8. 下載謄本PDF檔案
  9. 將下載的PDF檔案移動到案件資料夾的「0.謄本」子資料夾中

步驟 3：謄本結構化處理

  1. 點擊左側的「電子謄本結構化」按鈕
  2. 選擇剛才下載的PDF謄本檔案（可一次選擇多個）
  3. 系統會自動：
  4. 讀取PDF內容
  5. 辨識文字（使用OCR技術）
  6. 解析謄本結構
  7. 提取重要資訊（地號、面積、所有權人、權利範圍等）
  8. 產生結構化資料檔案
  9. 處理完成後，會產生三種格式的檔案，儲存在「output」資料夾中：
  10. JSON 格式：機器可讀的結構化資料（用於後續程式處理）
  11. TXT 格式：詳細的文字分析報告（方便人工閱讀）
  12. Excel 格式：結構化的表格資料（方便檢視和編輯）

處理時間：每個謄本約需 30-60 秒，視複雜度而定

步驟 4：讀取結構化資料

  1. 點擊中間的「讀取結構化JSON」按鈕
  2. 選擇剛才產生的JSON檔案（可一次選擇多個）
  3. 系統會自動：
  4. 讀取結構化資料
  5. 轉換為「物件調查表」格式
  6. 檢查資料一致性（地號是否與 data.json 相符）
  7. 儲存為 data_final.json（位於「4.其他相關」資料夾）

資料一致性檢查： - 如果地號順序與 data.json 不一致，系統會提示： - 選項 1：調整 data.json 順序 - 選項 2：調整謄本JSON順序（建議） - 選項 3：暫不處理

步驟 5：執行其他查詢（可使用連續模式）

方法 A：手動逐一執行

回到主頁，依序點擊各功能按鈕： - 使用執照查詢 - 重要設施查詢 - V523 系統 - 國土測繪圖資 - 高雄都市計畫 - 國土分區查詢 - 地質雲查詢 - 實價登錄

方法 B：使用連續模式（建議）

  1. 點擊主頁右欄的「連續模式」按鈕（淺藍色）
  2. 選擇「買賣」快速選項（自動勾選所有相關功能）
  3. 或手動勾選需要的功能
  4. 點擊「開始執行」
  5. 系統會依序自動開啟各查詢網站
  6. 手動操作：在每個網站完成查詢後，截圖或儲存結果

連續模式優點： - 自動排隊執行 - 節省時間 - 不會遺漏任何項目

步驟 6：計算土地增值稅

回到「謄本與土增稅」頁面：

方法 A：使用財政部系統（官方計算）

  1. 點擊「財政部土增稅」按鈕
  2. 系統會自動開啟財政部土地增值稅試算系統
  3. 系統會自動填入地段地號（從 data.json 讀取）
  4. 手動操作：補充其他資訊（前次移轉現值、本次移轉現值等）
  5. 查看計算結果，並截圖儲存

方法 B：使用高雄市系統（快速估算）

  1. 點擊「高雄土增稅估算」按鈕
  2. 系統會自動開啟高雄市土地增值稅估算系統
  3. 系統會自動填入地段地號
  4. 手動操作：補充移轉資訊
  5. 查看估算結果，並截圖儲存

步驟 7：編輯物件資料（補充資訊）

  1. 點擊右側的「編輯物件資料」按鈕
  2. 在彈出的編輯視窗中補充資訊：

基本資訊 - 案件編號 - 案件名稱 - 物件地址

價格資訊 - 總價 - 土地單價 - 建物單價

坪數資訊 - 土地坪數 - 建物坪數 - 主建物坪數 - 附屬建物坪數 - 公共設施坪數

格局資訊 - 房間數 - 廳數 - 衛浴數

設備與現況 - 屋況（新成屋/中古屋） - 裝潢（精裝/簡裝/毛胚） - 車位（有/無，平面/機械） - 其他設備

稅賦資訊 - 地價稅 - 房屋稅 - 管理費

  1. 編輯完成後，點擊「儲存」

步驟 8：檢查與整理

  1. 開啟案件資料夾，確認所有子資料夾都有檔案：
  2. 0.謄本：PDF謄本檔案
  3. 1.基本資料：查詢截圖（V523、使用執照等）
  4. 2.照片：物件照片（手動放入）
  5. 3.行情：實價登錄截圖
  6. 4.其他相關：data.json、data_final.json
  7. 5.委託：委託書等文件（手動放入）

  8. 6.成交：成交文件（手動放入）

  9. 檢查 data_final.json 是否完整

最終輸出

完成以上步驟後，您會獲得： - 完整的案件資料夾：包含所有查詢結果和文件 - data.json：地段地號基礎資料 - data_final.json：完整的物件調查表資料（可用於報告生成） - 結構化謄本資料：儲存在 output 資料夾（可重複使用）

11. 電子謄本結構化

功能：將PDF謄本轉換為結構化資料

處理內容： - 讀取PDF文字 - OCR辨識（處理掃描檔） - 解析謄本結構 - 提取重要欄位 - 產生結構化資料檔案

操作步驟： 1. 點擊「電子謄本結構化」按鈕 2. 選擇PDF謄本檔案（可多選） 3. 等待處理完成 4. 結構化檔案會自動儲存到「output」資料夾

處理時間： - 每個謄本約 30-60 秒 - 視謄本頁數和複雜度而定

輸出檔案（三種格式）： 1. JSON 格式：segment_地段-地號.json - 例如：segment_大寮區義堂段-358-21.json - 機器可讀的結構化資料

  1. TXT 格式：segment_地段-地號.txt
  2. 例如：segment_大寮區義堂段-358-21.txt

  3. 詳細的文字分析報告

  4. Excel 格式：segment_地段-地號.xlsx

  5. 例如：segment_大寮區義堂段-358-21.xlsx
  6. 結構化的表格資料

12. 讀取結構化JSON

功能：讀取謄本資料並轉換為物件調查表格式

處理內容： - 讀取JSON檔案 - 轉換為物件調查表格式 - 與 data.json 整合 - 資料一致性檢查 - 產生 data_final.json

操作步驟： 1. 點擊「讀取結構化JSON」按鈕 2. 選擇JSON檔案（從 output 資料夾） 3. 如有資料不一致，選擇處理方式： - 調整 data.json 順序 - 調整謄本JSON順序（建議） - 暫不處理 4. 確認後，系統會產生 data_final.json

輸出位置： - 案件資料夾/4.其他相關/data_final.json

資料一致性檢查： - 檢查地號順序是否與 data.json 相符 - 如不一致會影響後續報告生成

13. 財政部土增稅

功能：使用財政部系統計算土地增值稅

計算內容： - 土地增值稅稅額 - 一般稅率 - 自用住宅優惠稅率 - 重購退稅試算

操作步驟： 1. 點擊「財政部土增稅」按鈕 2. 系統開啟財政部土地增值稅試算系統 3. 系統會自動填入地段地號（從 data.json 讀取） 4. 手動操作： - 輸入前次移轉現值 - 輸入本次移轉現值 - 選擇稅率（一般/自用） - 查看計算結果 - 截圖儲存

注意事項： - 需要前次移轉資料（從謄本查詢） - 需要本次移轉現值（估算或實際成交價）

14. 高雄土增稅估算

功能：使用高雄市系統快速估算土地增值稅

估算內容： - 土地增值稅估算稅額 - 自動帶入公告現值 - 快速試算

操作步驟： 1. 點擊「高雄土增稅估算」按鈕 2. 系統開啟高雄市土地增值稅估算系統 3. 系統會自動填入地段地號 4. 手動操作： - 確認公告現值 - 輸入移轉資訊 - 查看估算結果 - 截圖儲存

注意事項： - 僅適用於高雄市 - 估算結果僅供參考，實際稅額以地政事務所核算為準

15. 編輯物件資料

  1. 物件個案調查表(租)
  2. 適用於租賃案件

常見問題

Q1：建立案件資料夾時，如何輸入地段地號？

A： - 縣市：從下拉選單選擇（例如：高雄市） - 行政區：從下拉選單選擇（例如：大寮區） - 地段：直接輸入地段名稱（例如：義堂段） - 不需要輸入「段」字 - 例如：義堂段 → 輸入「義堂」即可 - 地號：直接輸入地號（例如：358-21） - 如有子號，用「-」連接 - 例如：358地號21小段 → 輸入「358-21」

Q2：下載謄本需要付費嗎？

A：是的，從「全國地政電子謄本」下載需要付費： - 電子謄本：20元起計價 - 電傳謄本：10元起計價 - 需先註冊帳號並儲值 - 建議一次下載土地和建物謄本

Q3：電子謄本結構化需要多久時間？

A： - 每個謄本約 30-60 秒 - 處理時間視謄本頁數和複雜度而定 - 如謄本是掃描檔（圖片），需要使用OCR辨識，時間會較長

Q4：連續模式執行時可以中斷嗎？

A：可以，隨時點擊「停止」按鈕即可中斷執行。

Q5：資料一致性檢查是什麼？

A： 系統會檢查 data.json 中的地號順序，是否與謄本JSON的地號順序一致。

範例： - data.json：358-21（土地）、358-21（建物） - 謄本JSON：建物謄本、土地謄本

順序不一致時，系統會提示三種處理方式： 1. 調整 data.json 順序：修改 data.json 中的地號排列 2. 調整謄本JSON順序（建議）：重新排列選擇的謄本檔案 3. 暫不處理：跳過檢查，繼續處理

建議：選擇「調整謄本JSON順序」，確保資料正確對應。

Q6：為什麼有些功能只能在高雄市使用？

A： 部分功能（如V523、使用執照查詢、高雄土增稅估算）是使用高雄市政府的專屬系統，因此只能查詢高雄市的物件。

其他縣市請使用對應的縣市系統（需手動查詢）。

Q7：如何備份案件資料？

A： - 方法 1：直接複製整個案件資料夾 - 方法 2：壓縮案件資料夾為ZIP檔案 - 方法 3：使用系統的「封存」功能（如有提供）

建議定期備份到雲端硬碟（如 Dropbox、Google Drive）。

Q8：data.json 和 data_final.json 有什麼差別？

A： - data.json： - 只記錄地段地號基礎資料 - 由「地籍便民系統」自動建立 - 用於查詢時自動填入地號

  • data_final.json：
  • 包含完整的物件調查表資料
  • 由「讀取結構化JSON」和「編輯物件資料」產生
  • 用於報告生成（如有對應功能）

Q9：如果謄本PDF無法結構化怎麼辦？

A： 可能原因： 1. PDF檔案損壞：重新下載謄本 2. PDF為掃描檔（圖片）： - 系統會自動使用OCR辨識 - 處理時間會較長 - 辨識準確度視謄本清晰度而定 3. 謄本格式特殊：手動檢查並補充資料

如無法處理，可以手動將謄本資料輸入到「編輯物件資料」中。

Q10：連續模式執行時，每個網站都要手動操作嗎？

A： 是的。連續模式只是自動依序開啟各查詢網站，但每個網站的查詢和截圖仍需要手動操作。

系統無法完全自動化的原因： - 各網站有驗證碼或登入要求 - 需要人工判斷查詢結果是否正確 - 截圖位置和內容需要人工選擇

Q11：如何查看某個案件的所有資料？

A： 開啟案件資料夾，檢查各子資料夾： - 0.謄本：PDF謄本檔案 - 1.基本資料：查詢截圖（V523、使用執照等） - 2.照片：物件照片 - 3.行情：實價登錄截圖 - 4.其他相關：data.json、data_final.json - 5.委託：委託書等文件 - 6.成交：成交文件

或開啟 data_final.json 查看結構化資料。

Q12：土地增值稅試算結果為什麼與實際不同？

A： 土地增值稅試算僅供參考，實際稅額會受以下因素影響： - 前次移轉現值的準確性 - 本次移轉現值的估算 - 稅率選擇（一般/自用住宅優惠） - 其他加減項（如重購退稅、土地改良費用等）

建議：試算後，向地政事務所確認實際稅額。

Q13：如何新增其他縣市的功能？

A： 目前系統主要支援高雄市，其他縣市可以： 1. 使用通用功能（如國土測繪圖資、實價登錄等） 2. 手動開啟該縣市的查詢網站 3. 將查詢結果截圖儲存到案件資料夾

如需新增特定縣市的自動化功能，請聯繫系統開發人員。

Q14：編輯物件資料時，資料會自動儲存嗎？

A： 不會自動儲存，需要點擊「儲存」按鈕才會寫入 data_final.json。

建議：填寫過程中定期點擊儲存，避免資料遺失。

Q15：如果忘記輸入某項查詢怎麼辦？

A： 可以隨時回到主頁，點擊該功能按鈕重新執行。

或使用「連續模式」，只勾選遺漏的項目，系統會依序執行。

Q16：案件資料夾可以改名嗎？

A： 可以，但建議不要更改資料夾名稱，以免影響系統識別。

如需更改，請同步修改 data.json 中的相關資訊。

Q17：如何同時處理多個案件？

A： 1. 依序為每個案件建立資料夾 2. 使用「載入案件 data.json」切換不同案件 3. 或開啟多個系統視窗，分別處理不同案件

注意事項

1. 系統環境

  • 作業系統：Windows 10 或以上
  • 瀏覽器：建議使用 Google Chrome 或 Microsoft Edge
  • 網路連線：需要穩定的網路連線（查詢功能需要連網）
  • 硬碟空間：建議保留至少 10GB 空間（儲存案件資料）

2. 帳號準備

使用系統前，建議先註冊以下帳號： - 全國地政電子謄本：用於下載謄本（需付費） - 內政部實價登錄：用於查詢實價登錄（免費） - 各縣市查詢系統：依需求註冊（如高雄市V523等）

3. 資料夾管理

  • 不要手動修改資料夾結構：系統會自動建立7個子資料夾，請勿刪除或改名
  • 定期備份：建議每週備份案件資料夾到雲端硬碟
  • 清理舊案件：完成的案件可以封存或移到其他位置，釋放硬碟空間

4. 檔案命名

  • 謄本檔案：建議命名為「地段-地號_謄本類型.pdf」
  • 例如：義堂段-358-21_土地謄本.pdf
  • 截圖檔案：建議命名為「查詢項目_日期.png」
  • 例如：V523_20231201.png
  • 避免使用特殊字元：檔名不要包含 / \ : * ? " < > | 等字元

5. 查詢順序建議

建議依照以下順序執行查詢，效率最高： 1. 地籍便民系統（建立資料夾） 2. 全國地政電子謄本（下載謄本） 3. 電子謄本結構化 4. 讀取結構化JSON 5. 使用連續模式執行其他查詢 6. 計算土地增值稅 7. 編輯物件資料

6. 資料準確性

  • 謄本資料：以地政事務所核發的謄本為準
  • 實價登錄：僅供參考，實際成交價可能不同
  • 土地增值稅：試算結果僅供參考，實際稅額以地政事務所核算為準
  • 都市計畫：都市計畫可能變更，請以最新公告為準

7. 隱私保護

  • 不要分享帳號密碼：各查詢系統的帳號密碼請妥善保管
  • 注意個資保護：案件資料包含個人資訊，請勿外洩
  • 定期更改密碼：建議每3個月更改一次密碼

8. 系統更新

  • 定期檢查更新：系統會不定期更新，請注意更新通知
  • 備份後再更新：更新前請先備份重要案件資料
  • 閱讀更新說明：更新後請閱讀更新說明，了解新功能

9. 疑難排解

如遇到問題： 1. 重新啟動系統：關閉系統後重新開啟 2. 檢查網路連線：確認網路連線正常 3. 清除快取：清除瀏覽器快取 4. 重新登入：登出後重新登入查詢系統 5. 聯繫技術支援：如問題持續，請聯繫技術支援

10. 效能最佳化

  • 關閉不必要的程式：處理謄本時關閉其他程式，提升效能
  • 定期清理暫存檔：清理系統暫存檔，釋放硬碟空間
  • 不要同時處理太多謄本：建議一次處理不超過10個謄本
